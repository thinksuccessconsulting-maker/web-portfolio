# Yemi Odugbesan, Web Design Portfolio

A one-page portfolio of the small-business websites and web apps built by Yemi Odugbesan.

- Plain HTML: `index.html` is the whole site. There's no build step.
- Hosted on Netlify. `netlify.toml` publishes the top folder.
- To add a project, copy one `<article class="project">` block in `index.html`, change the text and link, and update the counts in the hero box (live projects, websites, web apps).
